## Commands
```bash
monosend receive
```
```bash
monosend receive --port 53318
monosend receive --autoaccept
```
```bash
monosend share file.txt file2.txt
```
```bash
monosend share --clipboard
```

## Installation
```bash
cargo install --path .
```
Make sure to have xclip or wl-clipboard for clipboard features
